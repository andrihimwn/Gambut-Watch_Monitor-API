🔒 Pengiriman & Privasi

Pilih bagaimana laporan disimpan. Data sensitif jangan dibagikan tanpa persetujuan.

Untuk pengiriman otomatis ke pusat, pengelola perlu menyediakan server/API, autentikasi, dan kebijakan akses. Tombol ini tidak mengirim data ke internet saat server belum disetel.

⇄ Cara kerja online & offline

Aplikasi dirancang ringan untuk relawan KPA di kampung.

🟢 Online

Browser dapat memuat peta/sumber eksternal jika nanti ditambahkan. Ekspor laporan bisa dikirim lewat kanal organisasi. Pengiriman otomatis membutuhkan server/API yang valid.

🟠 Offline

Formulir dan penyimpanan lokal dapat digunakan tanpa internet setelah file dibuka. Foto/video disimpan sebagai file di perangkat jika pengguna mengunduh atau menyimpannya terpisah.

🔐 Privasi

Data laporan disimpan dalam penyimpanan browser. Jangan menghapus data browser sebelum mengekspor laporan. Perangkat bersama tidak disarankan untuk laporan sensitif.
